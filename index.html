Project Overview

StudyCompanion AI is an AI-powered mobile learning companion designed to improve both academic productivity and emotional well-being among university and college students. The application combines intelligent learning assistance, personal task management, mood monitoring, and peer support into a single mobile platform.

Unlike conventional study applications that focus only on note-taking or scheduling, StudyCompanion AI integrates multiple intelligent services including an AI chatbot, local on-device language model support, emotion-aware mood tracking, productivity dashboards, and anonymous community support. The project emphasizes privacy-first AI processing while helping students maintain healthier study habits.

📚 Productivity

Organize study tasks, manage schedules, and monitor learning progress through an interactive dashboard.

🤖 AI Buddy

Receive AI-powered explanations, study guidance, and personalized academic support using local language models.

😊 Mood Track

Monitor emotional status, visualize mood history, and receive supportive recommendations for healthier learning habits.

Key Features

🤖

Chat AI

Provides instant academic assistance using AI-powered conversations. Students may ask programming questions, summarize learning materials, receive study suggestions, and interact through both text and voice input.

😊

Mood Check

Detects emotional conditions through facial expression analysis using TensorFlow Lite. The application records mood history and provides personalized recommendations to reduce stress.

📅

Dashboard

Displays academic schedules, task progress, productivity statistics, mood trends, and AI-generated daily summaries within a centralized workspace.

❤️

Support Room

Allows students to anonymously communicate with peers, exchange study experiences, and receive moderated emotional support in a safe community environment.

Data Flow

User interactions are processed by the Flutter application before being routed to different services. Academic records are stored locally using SQLite, AI requests are handled by the Gemma local model, while community communication is synchronized through Firebase. This hybrid architecture ensures both privacy and scalability.

Development Process

Stage 1: Planning

Requirements gathering, literature reviews of local AI integrations, and structuring basic system scoping documents.

Deliverables: Requirements analysis · Literature review · Feature planning

Stage 2: Design

Creating high-fidelity UI/UX concepts using vintage retro styling themes and designing component hierarchies mapping to user data endpoints.

Deliverables: Wireframes · Pixel UI · Database design

Stage 3: Development

Writing modular Dart components, setting up local SQLite caches, and optimizing tiny model file footprints internally.

Deliverables: Flutter implementation · SQLite integration · Firebase connection · AI integration

Stage 4: Testing

Conducting deep modular functional tests, monitoring model processing delays, and correcting navigational state faults.

Deliverables: Functional testing · UI testing · Performance optimization

Stage 5: Evaluation

Gathering core peer responses, verifying academic goals, and assembling comprehensive documentation files for final evaluation packages.

Deliverables: User feedback · Documentation · Future enhancement planning
